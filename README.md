# IPL Auction Analysis

Exploratory analysis of IPL auction data using Python, pandas, and data visualization.

## Project overview

This project explores IPL player auction data. It uses a Jupyter notebook to load the data, examine player prices, and visualize the relationship between base prices and final prices.

## Tools used

- Python
- Jupyter Notebook
- pandas
- matplotlib
- seaborn

## Dataset

The analysis uses `iplauction2023.csv`. Place the CSV file in the same folder as the notebook, or update the file path in the notebook to match its location.
